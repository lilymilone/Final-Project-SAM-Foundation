# Our Legacy sample files (synthetic)

These files describe a **made-up** event, the *Butterfly Spring Raffle (synthetic sample)*. They are not real Sabrina Audrey
Milone Foundation records. They exist to try and test the three ways to add history in Our Legacy:

| File | Type | What it tests |
|---|---|---|
| `butterfly_spring_raffle_recap.pdf` | PDF | Text extraction: date, place, attendance (120), revenue, goal, expenses, what worked, problems |
| `butterfly_spring_raffle_budget.csv` | CSV | The same expenses ($3,400) from a second source, and a planned budget ($3,000) for the cost-overrun check |
| `butterfly_spring_raffle_checkin.xlsx` | XLSX | A **conflicting** attendance figure (118 at the door vs 120 in the recap), which the board must resolve |
| `butterfly_spring_raffle_table.png` | Photo | Kept with the event; never read for numbers (an illustration, not a real photograph) |
| `butterfly_spring_raffle_notes.txt` | Notes | A lesson in the board's words, plus a deliberate prompt-injection line that must be screened out |

For "Tell us about an event", try: *We hosted a fundraiser in Garden City. Attendance was strong, guests especially enjoyed
the raffle, and we had challenges coordinating volunteers.*

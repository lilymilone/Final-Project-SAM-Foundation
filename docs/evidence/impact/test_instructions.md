**The proposal should include:**

1. Three plausible venue options
2. Venue and source research
3. A preliminary financial model
4. Fundraising revenue and expense assumptions
5. Important budget constraints
6. Historical event insights
7. An editable outreach draft
8. A final recommendation

**Steps:**

1. Do the task your usual way first (web search, spreadsheets, past notes, email). Press Start when you begin and Finish when you would be comfortable sharing the draft with the board. If you can't do this part, mark it unavailable: that is fine.

3. Link the agent run so the numbers come from the application's logs, then score both proposals with the same rubric.
4. Answer the short feedback form. Negative answers are just as useful as positive ones and are kept exactly as written.

_Use the same financial records and Our Legacy history for both attempts. Do not paste confidential donor details into notes._
